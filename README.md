# IGU-FitnessTracker

Práctica final realizada para la asignatura de Interfaces Gráficas de Usuario, 3º de Ingeniería informática en la Universidad de Salamanca. Software realizado con WPF y Visual Studio 2022 Community.

En el repositorio se encuentra la solución, el enunciado de la práctica y la memoria a realizar.

La práctica consiste resumidamente en realizar un aplicación de seguimiento de la actividad fisica del usuario.

" Hacer ejercicio puede parecer aburrido, pero si añadimos unos contadores de progreso y
unas visualizaciones atractivas quizá podamos ayudarnos a lograr esos soñados
abdominales. Este año nos vamos a poner en forma en la asignatura de Interfaces
Gráficas de Usuario, trabajando varios grupos musculares (brazos, espalda, piernas…)
a través de una serie de ejercicios (flexiones, sentadillas, crunch abdominal…). Para
ayudarnos, vamos a implementar una aplicación con la que registrar las ejecuciones de
los ejercicios (esto es, cuántas repeticiones he hecho, con cuánto peso adicional, y
cuándo las he hecho). Lo único obligatorio es la aplicación, pero el ejercicio físico está
recomendado.
Se debe crear una aplicación que permitirá al menos:
- Registrar las ejecuciones de un ejercicio seleccionado, incluyendo número de
repeticiones, peso con el que se realiza y fecha y hora.
- Visualizar el histórico de ejecuciones de un ejercicio, tanto en forma tabulada
como a través de un gráfico.
- Visualizar la cantidad de repeticiones por grupos musculares en una fecha dada "
